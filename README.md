# mi-pagina-web

Mi primera página web.

## Ver la página

Una vez activado GitHub Pages, la página estará disponible en:
https://jorgeherrera05.github.io/mi-pagina-web/

## Cómo editarla

1. Abre `index.html` y cambia el texto que está dentro de `<main>`.
2. Guarda los cambios, haz un commit y súbelos a GitHub.
3. GitHub Pages actualiza la página en uno o dos minutos.
